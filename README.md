# Zenex Desktop Application

This repository hosts the **compiled, source‑free** distribution of **Zenex** (v0.1 beta) for Windows.

## What is Zenex?
Zenex is a desktop AI‑assistant powered by the Groq API. It provides an intuitive UI for interacting with large‑language models.

## Installation
1. Download the latest release ZIP from the **Releases** page.
2. Extract the zip to a folder of your choice.
3. Run `Zenex.exe`. On first launch you will be prompted for a **Groq API key**. The application will not start without a valid key.

## Requirements
- Windows 10/11 (64‑bit)
- .NET runtime (bundled with the executable)
- Internet connection for API calls
